> 版本: 1.0 | 最后更新: 2026-05-08
> 状态: ✅ 已确认

## 1. 项目愿景

### Core Fantasy

> "我是自己人生的 RPG 主角。我选择的技能树定义了我想成为的人，而每日 Todo 是我打怪升级的方式。"

### Core Loop

```
选择技能方向 → 接受每日修炼任务 → 完成获得 EXP/成就 → 解锁新技能 → 成为更强大的自己
```

### 目标用户

- 想要用游戏化方式坚持自我提升的人
- 喜欢 RPG/成长类游戏但没时间玩的人
- 需要外部激励来养成习惯的人

## 3. 页面设计

### 3.1 角色页 ⚔️

**用途**: 展示玩家核心状态，RPG 角色面板风格

**布局（从上到下）**:
1. **顶部横幅**
   - 等级圆形徽章（Lv 角标），金色边框发光
   - 角色名 + 称号（称号随等级变化）
2. **属性条阵**
   - HP 条（角色红）— 带数值
   - MP 条（MP 蓝）— 带数值
   - EXP 条（技能琥珀）— 带数值 + 百分比数字
3. **资源卡片行**（三列）
   - Gold 🪙 / SP ⬡ / 连续天数 🔥
4. **装备槽位**（Phase 2，Phase 1 隐藏或灰色占位）

**交互**:
- 首次打开 App 时 HP +20（每日恢复）
- EXP 满时自动升级（触发简易动画）
- 点击等级徽章可查看详细统计（Phase 2）

### 3.2 任务页 📋

**用途**: 今日 Todo 管理，核心游戏循环的入口

**布局**:
1. **页头** — 「今日修炼」标题 + 添加按钮
2. **任务列表** — 按时间/优先级排列

**任务卡片设计**:
```
[○ / ✓] 任务标题              [+50 EXP] [+20 Gold]
         ⚔️ 难度 2  |  🌳 编程
```

- **圆形按钮**: 空心=待完成，打钩=已完成，闪动=推荐任务
- **难度标记**: ⚔️ + 数字（1-3），颜色与难度关联
- **技能标记**: 🌳 + 所属技能分支名
- **奖励标签**: EXP 奖励 + Gold 奖励（圆角标签）
- **已完成**: 文字灰色+删除线

**任务创建模式**: 系统预设 + 自定义

**系统预设任务生成规则**:
- 每天自动生成 3-5 个推荐任务
- 基于用户已激活的技能树分支
- 难度平均分配（1 简单 / 2 普通 / 3 困难）
- 任务类型: daily（每日重置）

**自定义任务**:
- 用户通过"添加"按钮创建
- 设置: 标题 / 难度(1-3) / 关联技能分支 / 类型
- EXP/Gold 奖励根据难度自动计算

**任务完成流程**:
```
点击 ○ → 完成动画(EXP 飘字) → dispatch(completeTodo)
→ dispatch(addExp) → dispatch(updateStreak) → dispatch(checkAchievements)
```

**任务失败流程**:
```
长按/左滑 → 失败确认 → dispatch(failTodo)
→ dispatch(damageHp) → dispatch(deductExp)
```

### 3.3 技能树页 🌳

**用途**: 7 大技能分支的可视化加点界面

**布局**:
1. **顶部标签栏** — 横向滚动切换 7 分支
2. **分支标题** — 图标 + 名称 + 当前等级 + 可用 SP
3. **技能卡片阵** — 按层级排列（每层 1-2 个技能）
4. **底部分支 EXP 条** — 关联任务积累

**7 大技能分支**:

| # | 分支 | 色值(深) | 色值(浅) | 示例技能 |
|---|------|----------|----------|---------|
| 1 | 💻 编程 | #c47b7b | #b87373 | Git 基础 → 数据结构 → 算法 → 系统设计 |
| 2 | 🎨 绘画 | #7bb5a8 | #6ba89a | 素描 → 色彩理论 → 数字绘画 → 构图 |
| 3 | 🌐 语言 | #c9a96e | #b8955e | 词汇 → 语法 → 会话 → 写作 |
| 4 | 🔧 硬件 | #8a9cc4 | #7a8cb4 | 电路基础 → Arduino → PCB → 嵌入式 |
| 5 | 📖 阅读 | #c47b7b | #b87373 | 速读 → 精读 → 笔记 → 知识体系 |
| 6 | 🏃 运动 | #7bb5a8 | #6ba89a | 跑步 → 力量 → 柔韧 → 综合 |
| 7 | 🎵 音乐 | #c9a96e | #b8955e | 乐理 → 乐器 → 创作 → 表演 |

**技能卡片状态**:
| 状态 | 样式 | 操作 |
|------|------|------|
| 已解锁 | 亮色 + 边框发光 | — |
| 可解锁 | 亮色 + 脉冲边框 | 点击消耗 SP 解锁 |
| 未解锁 | 灰色 + 前置条件文字 | — |
| 隐藏 | 深灰 ??? | Lv.X 解锁 |

**加点流程**: 完成关联任务 → 分支 EXP 增长 → 达到阈值自动升级 → 消耗 SP 手动解锁新技能

### 3.4 成就页 🏆

**用途**: 成就收集展示，激励用户完成里程碑

**布局**:
1. **进度概览条** — 已解锁 / 未解锁 / 完成度 %
2. **分类筛选器** — 全部 / 编程 / 绘画 / 语言 / 通用 / 隐藏
3. **成就卡片列表**

**成就卡片设计**:
```
[ 🏆 图标 ]  成就名称            [✓ 完成 / 70% / 🔒]
              成就描述
              进度条（进行中成就）
```

**成就类型**:

| 类型 | 说明 | 解锁方式 |
|------|------|---------|
| 🏆 通用 | 打卡/升级/任务相关 | 自动检测 |
| 💻 分支 | 各技能树专属 | 分支 EXP/技能等级 |
| 🎯 挑战 | 高难度目标 | 特定条件 |
| ❓ 隐藏 | 条件不显示 | 达成后揭示 |

**解锁效果**: 弹出动画 + 成就弹窗

## 4. 游戏机制

### 4.1 资源系统

| 资源 | 说明 | 获取 | 消耗 |
|------|------|------|------|
| HP | 血量 | 每日首次打开 App +20 | 任务失败 -10/20/30(按难度) |
| MP | 专注力(展示用) | 每小时 +5 | Phase 1 无消耗 |
| EXP | 经验值 | 完成任务奖励 | 任务失败扣奖励×0.3 |
| Gold | 金币(展示用) | 任务奖励 | Phase 1 无消耗 |
| SP | 技能点 | 升级 +1/级 | 解锁技能 |

### 4.2 等级系统

```
升级所需 EXP: expToNext = 100 × (level ^ 1.5)
每级奖励: +1 SP
```

| 等级 | 所需 EXP | 累计 EXP |
|------|----------|---------|
| 1→2 | 100 | 100 |
| 2→3 | 283 | 383 |
| 3→4 | 520 | 903 |
| 4→5 | 800 | 1703 |
| 5→6 | 1118 | 2821 |
| 10→11 | 3162 | 15778 |

### 4.3 任务惩罚机制

```
任务失败惩罚:
- HP 扣减: 难度 1=10 / 难度 2=20 / 难度 3=30
- EXP 扣减: 任务奖励 EXP × 0.3
- 连续打卡中断
```

### 4.4 连续打卡

- 每天完成至少 1 个任务 = 打卡成功
- 打卡天数连续累计
- 中断（全天 0 任务完成）= 归零

## 5. 数据持久化

- 方案: AsyncStorage
- 写入策略: 每次状态变化后 debounce 500ms
- 存储内容: 完整 Redux store
- 读取时机: App 启动时 hydrate

## 7. Phase 规划

### Phase 1 — MVP

**核心循环**: 角色 + 任务 + 技能树(3分支) + 成就 + 持久化

| 模块 | 交付内容 |
|------|---------|
| 导航 | 4 Tab 底部导航，深色/浅色主题切换 |
| 角色 | 等级/HP/MP/EXP/Gold/SP 展示，每日 HP 恢复，升级动画 |
| 任务 | 系统预设 3-5 个，自定义添加，完成/失败操作 |
| 技能树 | 3 分支 (编程/运动/阅读)，层级可视化，SP 加点 |
| 成就 | 10+ 通用成就，自动解锁检测 |

- 7 分支完整技能树
- 装备槽位系统
- 装备耐久度惩罚
- 周/月统计数据
- 成就合成系统
- 用户自建技能分支
- 动画特效增强

## 8. 关键 UX 流程

### 首次启动
```
冷启动 → AsyncStorage hydrate → 检测首次 → 显示简短引导
→ 每日首次 HP +20 → 渲染首页
```

### 完成任务
```
点击任务 ○ → 打钩动画 → EXP + 飘字 → 更新 EXP 条
→ 检测升级(动画) → 检测成就 → 更新连续打卡
```

### 每日刷新
```
App 进入前台 → 检测日期变更 → 重置 daily 任务状态
→ 生成新的预设任务 → HP +20(如果当天首次)
```
