## 1. 核心架构

### 1.1 分支架构

每分支 **7 层天赋树**（6 层选择 + 💎 终极）：

```
🌱 Tier 1 (入门 · SP:1)  →  2 技能选 1
🌿 Tier 2 (基础 · SP:1)  →  2 技能选 1，依赖 Tier 1
🌳 Tier 3 (进阶 · SP:2)  →  2 技能选 1，依赖 Tier 2
🔥 Tier 4 (专业 · SP:2)  →  2 技能选 1，依赖 Tier 3
⚡ Tier 5 (专家 · SP:3)  →  2 技能选 1，依赖 Tier 4
🌟 Tier 6 (大师 · SP:3)  →  2 技能选 1，依赖 Tier 5
💎 Tier 7 (宗师 · SP:5)  →  唯一终极技能，依赖 Tier 6
```

### 1.2 技能精通度

| 技能等级 | 称号风格 | 被动倍率 | 解锁条件 |
|----------|---------|---------|---------|
| Lv.1 🔰 | 入门/学徒/新兵 | 100% base | 消耗 SP 解锁 |
| Lv.2 🌟 | 进阶/师/工匠 | 150% base | 累积技能 EXP |
| Lv.3 👑 | 大师/王者/宗师 | 250% base | 大量技能 EXP |

### 1.3 被动效果类型

| 效果 ID | 效果 | 适用场景 |
|---------|------|---------|
| `exp_multiplier` | 任务 EXP 倍率 | 特定分支或全局 |
| `gold_multiplier` | Gold 倍率 | 特定分支或全局 |
| `hp_regen` | 完成任务额外 HP 恢复 | 续航 |
| `max_hp_bonus` | 最大 HP 上限提升 | 坦克流 |
| `hp_penalty_reduce` | 失败 HP 惩罚减免 | 容错流 |
| `sp_discount` | SP 消耗折扣 | 发育流 |
| `extra_daily_task` | 每日额外预设任务 | 肝帝流 |
| `streak_protect` | 连续打卡保护 | 稳定流 |
| `bonus_difficulty_exp` | 特定难度 EXP 加成 | 挑战流 |

### 5.1 数据结构

```typescript
interface PassiveEffect {
  type: 'exp_multiplier' | 'gold_multiplier' | 'hp_regen' | 'max_hp_bonus' |

        'streak_protect' | 'bonus_difficulty_exp';
  value: number;       // base at Lv.1

  scope?: 'branch' | 'global' | 'difficulty';
  branch?: SkillBranch;
  difficulty?: TodoDifficulty;
```
